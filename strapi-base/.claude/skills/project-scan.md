# Skill: project-scan

Scan a Next.js project and write/update `ai-memory.md` with full project context.

## Inputs
- `workspace_path` — absolute path to the project root

---

## Execution Steps

### Step 1 — Read package.json
Read `{workspace_path}/package.json`. Extract:
- Project `name`
- `next` version, `react` version, `tailwindcss` version
- Detect package manager: `bun.lockb` → bun | `yarn.lock` → yarn | `pnpm-lock.yaml` → pnpm | else → npm
- List other notable UI libraries (shadcn, radix, framer-motion, etc.)

### Step 2 — Map File Structure
List files 2 levels deep in:
- `src/app/` — routes and layouts
- `src/components/` — shared UI components
- `src/app/_components/` — page-level components (if exists)
- `src/hooks/` — custom React hooks (if exists)
- `src/utils/` or `src/lib/` — utilities (if exists)
- `src/styles/` — stylesheets (or wherever globals.css lives)
- `public/` — static assets

Build a clean directory tree string from these results.

### Step 3 — Inventory Components
For each `.tsx` file in `src/components/` and `src/app/_components/`:
1. Read the first 40 lines
2. Extract: component name (from `export function` or `export default`), props interface, JSDoc if present
3. Infer purpose from name if no docs

Record as table row: Component | Path | Purpose

### Step 4 — Inventory Custom Hooks
For each `.ts` or `.tsx` file in `src/hooks/`:
1. Read first 20 lines
2. Extract hook name and what it returns/does

Record as table row: Hook | Path | Purpose

### Step 5 — Extract Design Tokens
Locate `globals.css` (check `src/styles/globals.css`, then `src/app/globals.css`, then `app/globals.css`).
Read the file. Extract all CSS variables from `@theme {}` or `:root {}` blocks.

For each variable, record:
- CSS var name (e.g. `--color-primary`)
- Raw value (e.g. `oklch(...)` or `#hex` or `16px`)
- Inferred usage: color | spacing | font-size | font-family | radius | shadow | other

Record as table row: CSS Variable | Value | Usage

### Step 6 — Inventory Icons
List files in:
- `{workspace_path}/public/icon/` — check for size subdirs (16, 20, 24, 32, etc.)
- `{workspace_path}/public/other/` — logos, avatars, misc SVGs
- `{workspace_path}/public/icons/` — alternate naming (if exists)

For each subdirectory, record the list of filenames (without `.svg` extension).

### Step 7 — Detect Layout Fonts
Read `{workspace_path}/src/app/layout.tsx` (or `app/layout.tsx`).
Extract font variable names from `next/font` imports (e.g. `--font-geist`, `--font-dubai`).

### Step 8 — Preserve Existing Memory
If `{workspace_path}/ai-memory.md` already exists:
- Read and extract the entire `## Session Log` section content
- Read and extract the entire `## Notes` section content
These will be preserved verbatim in the new file.

### Step 9 — Write ai-memory.md
Write to `{workspace_path}/ai-memory.md` using the exact template below.
Fill in all `{placeholders}`. Preserve Session Log and Notes from Step 8.
